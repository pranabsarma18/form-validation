# Form Validation

A simple browser form validation project built with HTML, CSS, and JavaScript.

## Features

* Email validation
* Country selection
* Country-specific postal code validation
* Password validation
* Password confirmation
* Live inline validation
* Custom error messages
* CSS validation using `:user-valid` and `:user-invalid`

## Built With

* HTML
* CSS
* JavaScript

## Project

This project was created as part of **The Odin Project – Form Validation with JavaScript**.
